i
DÙNG TRONG XCODE

Ba bước để bắt đầu.

  1. 01
    Tải file ZIP

    Giải nén file vừa tải về máy.

  2. 02
    Mở Assets.xcassets

    Kéo thư mục AppIcon.appiconset vào trong.

  3. 03
    Chọn App Icon

    Vào Target → General → App Icons Source.

A
DÙNG TRONG ANDROID STUDIO

Ba bước để bắt đầu.

  1. 01
    Tải file ZIP

    Giải nén file vừa tải về máy.

  2. 02
    Trộn vào res

    Chép nội dung thư mục res (mipmap-*, drawable-*, values/ic_launcher_colors.xml) vào app/src/main/res. Không chép cả thư mục res (tránh res/res).

  3. 03
    Khai báo launcher

    Gán android:icon="@mipmap/ic_launcher" và android:roundIcon="@mipmap/ic_launcher_round" trên <application>.

Icon Composer và Xcode mới

Gói PNG legacy này phù hợp với asset catalog truyền thống. Với Xcode mới, hãy đưa artwork nguồn vào Icon Composer để tạo các biến thể Default, Dark, Tinted hoặc Clear theo workflow của Apple.
